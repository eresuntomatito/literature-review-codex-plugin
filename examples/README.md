# Example Usage

This plugin is designed to be installed once and used inside separate review projects.

Example prompt:

```text
Use the literature review plugin to run a structured narrative review from the PDFs in literature_review/00_raw_sources.
```

Example target project layout:

```text
my-review-project/
  literature_review/
    00_raw_sources/
      source-a.pdf
      source-b.pdf
    01_process/
    02_deliverables/
    03_knowledge_base/
```

The plugin supplies the workflow, templates, prompts, and helper scripts. The project supplies the citable evidence.
