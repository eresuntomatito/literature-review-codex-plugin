# Prompt: Review Framing

Use this prompt to frame a new literature review run.

## Instruction

Given the user's topic, audience, and intended output, draft a review protocol.

Use only the project evidence base for source claims. Do not cite sources that are not registered in the project.

## Required Output

- Review purpose
- Guiding question
- Recommended review type
- Inclusion criteria
- Exclusion criteria
- Proposed output structure
- Human decisions needed
