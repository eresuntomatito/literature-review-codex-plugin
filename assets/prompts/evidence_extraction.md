# Prompt: Evidence Extraction

Use this prompt to extract review-relevant evidence from a source.

## Instruction

Extract only claims, definitions, concepts, methods, frameworks, findings, and limitations that are present in the ingested source. Keep quotations distinct from paraphrases.

## Required Output

Populate extraction-table rows with:

- source_id
- page_or_location
- evidence_type
- extracted_text_or_paraphrase
- claim_supported
- concept_or_theme
- relevance_to_review_question
- verification_status
