# Prompt: Source Card Generation

Use this prompt to create a compact source card from an ingested source.

## Instruction

Read the extracted source text and produce a lean source card. Preserve traceability to the raw source. Do not use outside knowledge.

Create source cards only for sources that are included or marked as high-value transferable method fit.

## Required Output

- Citation metadata if available
- Purpose of source
- Methods or approach
- Up to three useful findings or claims
- Limitations
- Relevance to current review
- Notes for future retrieval

Keep the card compact. Evidence detail belongs in the extraction table.
