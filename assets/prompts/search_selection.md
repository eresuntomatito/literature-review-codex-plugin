# Prompt: Search And Selection

Use this prompt to support search planning and candidate selection.

## Instruction

Given the review protocol, draft or refine a search strategy, candidate-recording plan, and stopping rule. Search results and metadata are planning records only and are not citable evidence.

## Required Output

- Database order
- Primary search string
- Fallback strings
- Search logging requirements
- Candidate inclusion priorities
- Candidate exclusion rules
- Stopping rule
- Conditions for supplemental gap search
