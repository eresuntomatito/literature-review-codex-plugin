# Prompt: Corpus Adequacy Assessment

Use this prompt after triage or preliminary screening and before deep synthesis.

## Instruction

Assess whether the current included-source set is adequate for the approved review question and subquestions. Use only project tables and ingested-source artifacts. Do not cite candidate records as evidence.

## Required Output

- Corpus snapshot
- Screening counts
- Coverage by review need
- Representative source IDs per need
- Weak or missing coverage areas
- Whether supplemental search is needed
- Scope qualifications needed for the final deliverable
- Recommended next step
