# Prompt: Synthesis

Use this prompt to synthesize extracted evidence.

## Instruction

Compare extracted evidence across sources. Identify convergence, divergence, gaps, and possible synthesis statements. Every synthesis statement must cite source IDs and evidence IDs.

## Required Output

- Theme or argument
- Supporting sources
- Supporting evidence IDs
- Convergent findings
- Divergent findings
- Gaps
- Draft synthesis statement
- Confidence level
- Verification needs
